# 📊 Finanzas Corporativas — Test Interactivo

Aplicación web interactiva progresiva (PWA) de alto rendimiento para el estudio y autoevaluación de **Finanzas Corporativas y Matemática Financiera** (Grado en ADE).

🔗 **Aplicación en directo:** [https://carloshrnndz.github.io/fincop/](https://carloshrnndz.github.io/fincop/)

---

## ✨ Características Principales

* **20 Unidades Temáticas Completas (200 preguntas)**: Banco íntegro de preguntas con respuestas justificadas conceptualmente y ejemplos prácticos numéricos.
* **📐 Fórmulas Matemáticas y Financieras con KaTeX**: Notación nítida de Interés Compuesto, Descuento Comercial, VAN, TIR, CAPM, WACC, Préstamo Francés, Alemán y Americano.
* **🧮 Calculadora Financiera Integrada**: Herramienta flotante con soporte para potencias, memoria `Ans`, cálculo de tantos efectivos y atajo directo con la tecla **`C`**.
* **🖥️ Diseño Apaisado Especial para Escritorio**: Interfaz widescreen en 2 columnas (dashboard) y doble panel (pregunta + explicación lateral simultánea) sin scroll innecesario.
* **⌨️ Atajos de Teclado**: Control ágil con teclas `1`-`4` o `A`-`D`, flechas de navegación, `M` para marcar y `Enter` para avanzar.
* **🔊 Lectura por Voz (TTS)**: Locución en español de preguntas y opciones mediante Web Speech API.
* **📱 Progressive Web App (PWA)**: Funcionamiento offline con Service Worker e instalable en dispositivos móviles o escritorio.
* **☁️ Sincronización Multi-dispositivo**: Soporte para código de sesión con Firebase y persistencia local en `localStorage`.

---

## 🚀 Tecnologías

* **HTML5 / CSS3** (Vanilla, CSS Grid, Flexbox, Glassmorphism, Theme Obsidian & Emerald)
* **JavaScript ES6+** (Sin dependencias pesadas de build)
* **KaTeX** (Renderizado matemático $\LaTeX$)
* **Canvas Confetti**
* **Web Speech API**
* **Service Workers & Cache API**
